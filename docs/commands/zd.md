## zd

Cross-platform CLI for the Zenduty / Xurrent IMR REST API

### Synopsis

zd is a fast, scriptable command-line interface for the Zenduty / Xurrent
Incident Management & Response (IMR) REST API.

The same binary also runs as 'ximr' through a symlink installed by every
distribution channel.

Pick a profile in ~/.config/zd/config.yaml or pass --token / --host on
each invocation. Output defaults to a human-readable table on a TTY and
to JSON when piped, so scripts and AI-driven skills get clean structured
data without extra flags.

### Options

```
      --account-id string   5-character account identifier; required for the 'zd event fire' command
      --config string       config file path (default: $XDG_CONFIG_HOME/zd/config.yaml or ~/.config/zd/config.yaml)
      --debug               log wire-level requests/responses to stderr
      --debug-curl          print a copy-paste curl reproduction of every request to stderr
  -h, --help                help for zd
      --host string         API base URL (default: https://www.zenduty.com)
      --no-color            disable color output
      --output string       output format: json | yaml | table | template (default: table on TTY, json when piped)
      --profile string      config profile name (default: profiles.default_profile in the config file)
      --template string     Go text/template body, used when --output=template
      --token string        API token (overrides env and profile)
```
