## zd config init

Create or update a profile in the config file

### Synopsis

Interactively create a new profile (or update an existing one) and write it
to the config file. Pass --no-interactive to write a profile from flags only.

Generate an API token at: https://www.zenduty.com (Account -> API Keys).

